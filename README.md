# Eslamy - Islamic Mobile Application (Flutter)

A cross-platform mobile application built with **Flutter** and **Dart**, featuring Quran audio recitation, dynamic prayer times based on geolocation, Azkar, and Islamic content.

---

## Features

- **Prayer Times & Geolocation:** Accurate calculation of prayer times using `geolocator`.
- **Quran Audio Streaming:** Audio recitation playback using `audioplayers`.
- **Clean UI & Islamic Aesthetics:** Intuitive, responsive design with dark and light themes.
- **State Management:** Built using `provider` for clean reactive architecture.
- **Cross-Platform:** Runs smoothly on both Android and iOS.

---

## Tech Stack

- **Framework:** Flutter (Dart SDK ^3.10)
- **State Management:** Provider
- **Location & GPS:** Geolocator
- **Audio Playback:** AudioPlayers
- **Networking:** HTTP

---

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/anasmhmd1/Eslamy-Flutter-App.git
   ```

2. Get Flutter packages:
   ```bash
   flutter pub get
   ```

3. Run on connected device or emulator:
   ```bash
   flutter run
   ```
